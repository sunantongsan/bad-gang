# โจ๋สามซอย · Jo Sam Soi

หัวโจกเฟรนช์บูลด็อกฝั่งหมาใน Bad Gang เสื้อทีมสีเขียวน้ำทะเล ผ้าผูกคอแดง และเบอร์ 3 กลางหลัง

[ดูคลิปซ้อมกับกระสอบและภาพช้าท้ายคลิป](./Jo-Sam-Soi-Combat.mp4) · [เทียบระยะหมัด](./Jo-Sam-Soi-Punch-Reach.jpg) · [ดูภาพตัวละคร](./Jo-Sam-Soi.jpg)

ต้นฉบับ [Blender](./Jo-Sam-Soi.blend) และ [GLB สำหรับเกม](./Jo-Sam-Soi.glb) ใช้โครงกระดูกหลัก 19 กระดูก พร้อมกระดูกเสริม 4 กระดูกสำหรับยืดแขนและวัสดุสีบนจุดยอด ตัวละครมีคลิปแอนิเมชันแยกให้เรียกตามชื่อ

| คลิป | ท่าทาง |
| --- | --- |
| `Idle` | ยืนพัก ขยับหูและหาง |
| `FightGuard` | ยกหมัดตั้งการ์ด ถ่ายน้ำหนักวน |
| `OneTwo` | ชกซ้าย–ขวาต่อเนื่อง ยืดกำปั้นตอนถึงเป้าแล้วดึงกลับเข้าการ์ด |
| `SlipUppercut` | โยกหลบ ลดไหล่ แล้วสวนหมัดเสย |
| `JumpKick` | ย่อเข่า กระโดดถีบ และลงพื้นกลับเข้าการ์ด |
