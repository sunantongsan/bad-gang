## ชุดลูกสมุนและอาวุธการ์ตูน

[ดูท่าใช้อาวุธและเปลี่ยนชุด](./Dog-Crew-Weapons.mp4) · [ดูชุดเดิมเทียบกับชุดใหม่](./Dog-Crew-Outfits.jpg)

| ลูกสมุน | ไฟล์พร้อมใช้ | ท่าใช้อาวุธ |
| --- | --- | --- |
| จิ๋ว ชุดวิ่งกลางคืน | [Night Runner GLB](../jiw-fai-laep/Jiw-Fai-Laep-Night-Runner.glb) | `BubbleTwirl` หมุนคทาฟองสบู่ |
| ป้อม ชุดช่าง | [Workshop GLB](../pom-tue/Pom-Tue-Workshop.glb) | `SpringBonk` เหวี่ยงค้อนหัวนิ่มแล้วเด้งกลับ |

ใน Blender เลือกโครงกระดูกแล้วเปิด **Object Properties → Custom Properties → Outfit** ตั้งเป็น `0` สำหรับชุดเดิม หรือ `1` สำหรับชุดลูกสมุน

GLB แต่ละชุดเปิดใช้ได้แยกกัน ตัวเดิมและชุดใหม่ของสุนัขแต่ละตัวมีร่างกาย โครงกระดูก อาวุธ และคลิปทั้ง 7 ท่าเหมือนกัน มีเพียงเมชชื่อ `Outfit | …` ที่ต่างกัน หากใช้ระบบแต่งตัวในเกม สามารถผูกเมชชุดใหม่เข้ากับโครงกระดูกเดิมของสุนัขตัวนั้นได้ อาวุธแสดงเมื่อเล่นคลิปใช้อาวุธ และเก็บเมื่อเข้าท่ามือเปล่า
